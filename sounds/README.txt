Put recorded sound files here. Each one replaces the game's synthesized version.

  screech.ogg    the shriek when the entity spots you   (.mp3 or .wav also work)
  jumpscare.ogg  the game-over jumpscare                 (optional, uses screech if missing)

If a file is missing, the game falls back to its built-in synthesized sound.
Use sounds you're allowed to use (CC0 / public domain is easiest: no credit needed).
